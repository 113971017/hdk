Detailed Description

Control and check status of the MCU Interrupt Controller.

  • enable interrupt
  • disable interrupt
  • change interrupt priority (if applicable)
  • check pending status
  • clean pending status
Warning
  • Application has to be in the System mode to call all these functions! Only the function Itc_IsPending() can be called in User mode.
  • After both cold and warm bootstraps the part is configured to be in the System mode by default. If the User mode is set by application after the bootstrap, the functions have to be called inside of the SYSTEM_MODE** section managed by the macros ENTER_SECTION and EXIT_SECTION** specified in <atomic.h>.

Set interrupt priority for specified interrupt source.

Parameters
inameInterrupt source (see itc_cfg.h for exact names)
prioInterrupt priority with range [3..6]
Note
  • There is no check inside the function if correct priority is specified. If incorrect priority is specified it is truncated to fit expected range.
  • Warning: Priority of the Interrupt Handler (ISR) shall be changed accordingly in the vectors.S file. Normally, ISR priority is "less by one" than priority of the interrupt source. I.e. if interrupt source is configured for priority 4, the ISR shall have priority 3.
Itc_SetPrio(ITC_STIMER1, 4);
