◆ RFTX_DIRECT_MOD

uint16_t RfTxGeneralConfig_Type::RFTX_DIRECT_MOD

3-bit modulation source selection:

  • 0 = Fixed logic 0
  • 1 = Raw data from FIFO, no preamble, sync pattern or packet
  • 2 = Preamble and sync pattern, no packet
  • 3 = Preamble, sync pattern and packet
  • 4 = GPIO0 input
  • 5 = GPIO1 input
  • 6 = GPIO2 input
  • 7 = GPIO3 input
