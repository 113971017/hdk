Detailed Description

Acknowledge (reset) watchdog and check acknowledgment windows status (open / closed).

  • Absolute watchdog period is ~260 ms, defined at system design time and can not be changed
  • Absolute watchdog is a window type watchdog which can be acknowledged only during a window which is open from 1/2 of the end of watchdog period. Acknowledgment outside the window will cause immediate chip [cold] reset.
