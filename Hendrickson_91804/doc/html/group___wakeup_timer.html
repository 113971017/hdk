void WakeupTimer_Init ( uint16_t  mant,
uint16_t  exponent 
)

Initialize wake up timer to new interval.

Parameters
mant8-bit mantissa (max 255) to specify wake up timer interval
exponent4-bit exponent (max 12) to specify wake up timer interval
Note
  • Wake-up timer is clocked from 1 kHz and can be configured to generate intervals from 1 ms to ~17.5 minutes
  • Period (in ms) = mant + 1, if exp = 0 Period (in ms) = (mant + 257) * 2^(exp-1), if exp > 0
  • The wake-up timer is running continuously and cannot be stopped. It is only possible to reload interval and restart the timer. After power-on reset wake-up timer starts with default period ~17.5 minutes.
  • Interrupt/wake-up is generated as long as WUPTMR_FLAG (timer overflow) is set. Flag WUPTMR_FLAG can be cleared by writing '1' to the flag.
  • Flag WUPTMR_FLAG is also acts as /b non-maskable wake-up source
