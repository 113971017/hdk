Detailed Description

Initialize and start / stop hardware timers.

Simple Timer properties:

  • 14 bits incrementing counter
  • Generate an interrupt when counter reaches the timer value
  • Reset counter when it reaches the timer value
  • Configurable clock source (CPU clock, 1us or 100us)

uint16_t  period 
)

Initialize and start timer.

Parameters
clock_sourceClock source for the timer as SimpleTimerClock_Type
periodTimer period (max 16383).
Note
  1. The timer starts counting from 1 and is incremented each clock period. When it reach value defined by period, an interrupt is generated and timer starts from 1 (auto-reloaded)
  2. Timer is explicitly stopped before writing new period value to VALUE. This guarantees that interrupt will be generated exactly after period-1 ticks after writing the period to the VALUE field. Otherwise, without the stop, first interrupt can be generated either immediately, if a new period is less than CURRENT timer value, or after period - CURRENT ticks.

Note
