enum TempSensorMode_Type

Temperature sensor mode (event generation)

Enumerator
TEMPSENS_DISABLED 

no events, temperature sensor is OFF

TEMPSENS_ENABLED_WITH_NO_EVENTS 

no events, temperature sensor ON, but no events are generated (polling mode)

TEMPSENS_EVENT_WHILE_BELOW_LOW_THRESHOLD 

event as long as temperature is below low threshold

TEMPSENS_EVENT_WHILE_ABOVE_LOW_THRESHOLD 

event as long as temperature is above low threshold

TEMPSENS_EVENT_WHILE_ABOVE_HIGH_THRESHOLD 

event as long as temperature is above high threshold

TEMPSENS_EVENT_WHILE_BELOW_HIGH_THRESHOLD 

event as long as temperature is below high threshold

TEMPSENS_EVENT_WHILE_OUT_OF_RANGE 

event as long as temperature is outside normal operating range

TEMPSENS_EVENT_WHILE_IN_RANGE 

event as long as temperature is within normal operating range
