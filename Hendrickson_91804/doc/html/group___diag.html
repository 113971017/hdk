Detailed Description

Monitor the signal to be within specified range using two comparators with configurable thresholds and hysteresis.

The purpose is to have 4 parallel interfaces available with programmable reference and channel selection. This will allow the system to monitor a set of four different signals and verify that they are inside a given window based on an upper and lower threshold independently programmable as ratios of the selected reference.
