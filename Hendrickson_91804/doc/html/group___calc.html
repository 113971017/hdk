Detailed Description

This group of functions implements different calculations:

  • compensation of the PVT sensors' variability and non-linearity with the next conversion to the corresponding physical units
  • computation of the memory data signature based on the ROM BIST hardware

uint32_t Calc_Pressure ( uint16_t  adc_raw_pressure,
uint16_t  adc_raw_temp,
uint16_t  adc_raw_volt 
)

Calculates Pressure in kPa units.

Besides the raw ADC pressure value the compensation requires the raw ADC temperature and voltage as well as the calibration coefficients factory stored in the nvRAM.

Parameters
adc_raw_pressureis a raw ADC pressure value returned by the function Adc_ReadPVT() or Adc_ReadPressure()
adc_raw_tempis a raw ADC temperature value returned by the function Adc_ReadPVT() or Adc_ReadTemperature()
adc_raw_voltis a raw ADC temperature value returned by the function Adc_ReadPVT() or Adc_ReadVoltage()
Returns
Pressure in [kPa] in UQ16.16 format (unsigned fixed point: 16-bit integer part, 16-bit fractional part). See notes below on how to convert UQ16.16 value to integer. Returns 0 if calculations can not be performed due to incorrect initial conditions.
Precondition
Because the function Calc_Pressure() reads some calibration data directly from the nvRAM, after each wake up and before calling the function the nvRAM has to be recalled by the library function NvRam_Recall().
Warning
Raw ADC value returned by low power measurement function cannot be used as adc_raw_pressure argument; please use Adc_ReadPVT() or Adc_ReadPressure() instead.
Note
  1. In order to get integer part of the pressure [in kPa], the value returned by the function Calc_Pressure() should be divided by 65536. The fractional part will be fully discarded (rounding towards 0).
    uint16_t pressure_in_kpa = Calc_Pressure(..) / 65536;
  2. Parameters adc_temp and adc_volt are used to compensate pressure over the different temperatures and voltages.

◆ Calc_RomBistFor()

uint32_t Calc_RomBistFor ( uint16_t  start_addr,
uint16_t  stop_addr 
)

Computes a 24-bit signature for the configurable memory range.

The signature is based on the polynomial: x^24 + x^23 + x^22 + x^17. The calculation is implemented by the ROM BIST hardware that reads the assigned memory data by means of the DMA.

Parameters
start_addris a 16-bit unsigned start address of the ROM BIST. The start address points to the first/lowest 16-bits word within the desired memory range. The start address has to be aligned on a word 32 bits (2 LSB are ignored).
stop_addris a 16-bit unsigned stop address of the ROM BIST. The stop address points to the last/highest 16-bits word within the desired memory range.
Returns
32-bit unsigned number that:
  • includes the calculated 24-bit signature, if the BIST calculation is successful;
  • is equal to 0xFFFFFFFF, if BIST calculation failed.
Precondition
  • If the assigned input memory range corresponds to the nvRAM, the NvRam_Recall() function has to be executed in advance to avoid the memory error.
  • Application has to be in the System mode to call this function!
  • After both cold and warm bootstraps the part is configured to be in the System mode by default. If the User mode is set by application after the bootstrap, the function has to be called inside of the SYSTEM_MODE** section managed by the macros ENTER_SECTION and EXIT_SECTION** specified in <atomic.h>.

◆ Calc_Temperature()

uint16_t Calc_Temperature ( uint16_t  adc_raw_temp)

Converts the raw ADC temperature value to the Celsius scale with an ofset 52 deg.C.

Besides the raw ADC temperature value the compensation requires the calibration coefficients factory stored in the nvRAM.

Parameters
adc_raw_tempis a raw ADC temperature value returned by the function Adc_ReadPVT() or Adc_ReadTemperature()
Returns
Temperature in [deg.C] in UQ8.8 format (unsigned fixed-point: 8-bit integer, 8-bit fractional) with offset +52.0 deg.C. See notes below on how to convert UQ8.8 value to integer.
Precondition
Because the function Calc_Temperature() reads some calibration data directly from the nvRAM, after each wake up and before calling the function the nvRAM has to be recalled by the library function NvRam_Recall().
Note
  1. In order to get integer part of the temperature [in deg.C], the value returned by the function Calc_Temperature() should be divided by 256 and then 52 should be subtracted. The fractional part will be fully discarded (rounding towards 0).
    int16_t temperature_in_c = Calc_Temperature(..) / 256 - 52;
  2. Offset +52.0 deg.C is introduced to simplify conversion to VDA format

◆ Calc_Voltage()

uint16_t Calc_Voltage ( uint16_t  adc_raw_volt)

Converts the Supply Voltage to the Volts scale.

The function does not require any special calibration. The voltage accuracy is ensured by the internal bandgap voltage reference.

Parameters
adc_raw_voltis a raw ADC voltage value returned by the function Adc_ReadVoltage()
Returns
Supply Voltage in Volts [V] multiplied by 100. Divide the output by 100 to get result expressed in Volts [V].
uint16_t voltage_in_v = Calc_Voltage(raw_v) / 100;
Warning
The resultant Supply Voltage accuracy can be a bit worse than it is specified in the datasheet, If the input argument adc_raw_volt takes the raw ADC voltage value returned by the function Adc_ReadPVT().
