Detailed Description

Provides acceleration measurements with configurable Low Pass Hardware Filter.

  • The initialization time of the HW filter and a delay between measurements are programmable.
  • The measured data is stored in a circular buffer having a fixed size = sixteen 16-bit words.
  • There are 2 functions to read either the latest available measurement or the new one as soon as it's ready after an appropriate delay.

Implementation details:

  • If the cap-filter refresh by HW is not available, the acceleration measurements are driven by the Simple Timer 1 interrupts. Interrupts are generated each 125 us to refresh the cap-filter. Then the measured acceleration is converted by ADC with specified sampling period (see period parameter in Accel_InitFilterForX() and Accel_InitFilterForZ() functions.
  • Otherwise, the cap-filter is refreshed by hardware and AD conversions are executed with configured period driven by the Simple Timer 1.
Warning
  • Application has to be in the System mode to call these functions!
  • After both cold and warm bootstraps the part is configured to be in the System mode by default. If the User mode is set by application after the bootstrap, the functions have to be called inside of the SYSTEM_MODE** section managed by the macros ENTER_SECTION and EXIT_SECTION** specified in <atomic.h>.

means No filtering, used by default ACCEL_SPARE<1:0>: 00b; ACCEL_SPARE<2>: 0b

HWF_TYPE_0 

Minimum filtering, ACCEL_SPARE<1:0>: 11b; ACCEL_SPARE<2>: 1b.

HWF_TYPE_1 

filtering, ACCEL_SPARE<1:0>: 10b; ACCEL_SPARE<2>: 1b

HWF_TYPE_2 

filtering, ACCEL_SPARE<1:0>: 01b; ACCEL_SPARE<2>: 1b

HWF_TYPE_3 

Maximum filtering, ACCEL_SPARE<1:0>: 00b; ACCEL_SPARE<2>: 1b.

◆ Accel_InitFilterForX()

void Accel_InitFilterForX ( HWFilterSetup_Type  filter_id,
uint16_t  user_init_time,
uint16_t  period 
)

Initializes HW filter and starts acceleration measurements for X sensitive axis.

Parameters
filter_idsets one of the available HW filter modes. For more details see HWFilterSetup_Type
user_init_timeis an initialization time of the HW filter expressed in 0.1 ms units. If set to zero, default initialization time is used that matches selected filter_id.
periodis a time between AD conversions expressed in 0.1 ms units. The minimal period value is 10 that corresponds to 1 ms.
Precondition
Because the function reads some calibration data directly from the nvRAM, after each wake up and before calling the function the nvRAM has to be recalled by the library function NvRam_Recall().
Note
  • The timing defined by the values filter_id and period fully depends on the accuracy of the HFO frequency (please see the device datasheet for details).
  • Supports re-initialization with new parameters.
  • Be aware that initialization can be lost if the ADC, Simple Timer or acceleration sensor is used in parallel.
  • Being stopped, the HW filter will gradually lose a charge on the internal capacitors that will require executing a new initialization.
