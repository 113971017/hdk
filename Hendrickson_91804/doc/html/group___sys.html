◆ Sys_CalibrateHfo()

bool Sys_CalibrateHfo ( void  )

The function calibrates 8 MHz RC oscillator of HFO by using a precise XTAL clock as a reference.

The calibration is done by binary search for the optimal trimming value for HFO_FREQ_TRIM register.

Returns
true if calibration failed.
Precondition
  • Application has to be in the System mode to call this function!
  • After both cold and warm bootstraps the part is configured to be in the System mode by default. If the User mode is set by application after the bootstrap, the function has to be called inside of the SYSTEM_MODE** section managed by the macros ENTER_SECTION and EXIT_SECTION** specified in <atomic.h>.
Warning
LF reception is switched off before the calibration and needs to be explicitly enabled after the calibration, if needed.

@ note

  • The execution time includes the XTAL oscillator start-up time specified below 1.4 ms with a typical value about 0.7 ms.
  • The XTAL oscillator start-up time takes the main part of the function's execution time.

void Sys_HaltWith ( LfMode_Type  lf_mode)

Enter into HALT power down mode.

Parameters
lf_modeLF mode, see LfMode_Type
Note
  • Software execution is halted and gets resumed from the next instruction on any enabled interrupt event
  • RFTX mode is not affected and keeps the operating mode set before
Warning
  • If watchdog is not handled timely by application, it might interrupt the HALT mode (if ISR_AWD_ATT is enabled) or prematurely or reset the chip. The maximum duration of the HALT mode should not exceed the watchdog period, that is ~260 ms

◆ Sys_SetNormalLfo()

void Sys_SetNormalLfo ( void  )

The function sets the Normal mode of LFO when its 32 kHz RC oscillator's output is always used to generate 1 kHz clock after 32x divider.

Note
  • The Normal LFO mode presumes a bit higher power consumption at sleep modes (see datasheet for details).
  • The Normal LFO mode can be useful to support the accurate delays below 3 ms by means of the Wake-Up timer.

◆ Sys_SetUlpLfo()

void Sys_SetUlpLfo ( void  )

The function sets the ULP mode of LFO when a smart switching between 32 kHz and 1 kHz RC oscillators is used to generate 1 kHz clock during both sleep modes.

Note
  • The ULP LFO mode provides the smallest power consumption at sleep modes (see datasheet for details).
  • The ULP LFO mode cannot support the accurate delays below 3 ms by using the Wake-Up timer.
