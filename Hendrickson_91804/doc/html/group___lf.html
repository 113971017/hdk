Detailed Description

Common functions to configure, start and stop the LF transceiver, as well as to return a state of the LF receiver.

◆ Lf_Init()

void Lf_Init ( const LfConfig_Type *  cfg)

Initialize LF block.

Parameters
cfgA pointer to configuration settings (see LfConfig_Type for details)
Precondition
  • It is strongly recommended to assign all values directly in the configuration data structure. Being not assigned, the value takes on zero.
Note
There are 3 gradations available for the LF gain (LF_GAIN_SEL): LF_GAIN_MIN, LF_GAIN_MID and LF_GAIN_MAX (see LfGain_Type for details). Zero LF_GAIN_SEL is not supported and can cause LFRX malfunction.

◆ Lf_Start()

void Lf_Start ( LfMode_Type  lf_mode)

Starts the LF transceiver in a specified mode.

Parameters
lf_modeA mode for LF transceiver (see LfMode_Type for details).
Note
  • LF front-end settling time is ~2ms from disabled state.
  • RFTx module is not affected by this function.
  • Modulation from any GPIO (lf_mode LFTX_DIRECT_FROM_GPIOx) is independent of the LF state machine.
