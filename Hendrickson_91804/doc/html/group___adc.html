Detailed Description

Get raw values (in ADC units) from sensors: Pressure, Temperature and Voltage.

Warning
  • Application has to be in the System mode to call all functions with prefix "Adc_Read"!
  • After both cold and warm bootstraps the part is configured to be in the System mode by default. If the User mode is set by application after the bootstrap, the functions have to be called inside of the SYSTEM_MODE** section managed by the macros ENTER_SECTION and EXIT_SECTION** specified in <atomic.h>.

◆ Adc_ReadGpio()

uint16_t Adc_ReadGpio ( GpioPinId_Type  gpio_id)

The function implements a single-ended voltage measurement on any GPIO pin.

Parameters
gpio_idGPIO0..GPIO3
Returns
an unsigned 16-bit value with a raw result of the AD conversion of the voltage on the assigned GPIO pin.
Precondition
Before calling this function, GPIO should be configured as GPIO_ANA_INPUT.
Note
  1. To implement the AD-conversion the function Adc_ReadGpio() calls the internal library function declared as "uint16_t adc_ll_read_gpio(void);".
  2. The measurement is implemented with ADC supporting 12-bit resolution that correspods to the typical input range from zero till 1.2V.
  3. The output value 4095 or above represents an ADC overflow.
  4. To implement an efficient averaging inside of the Adc_ReadGpio() function, an application can override the function adc_ll_read_gpio() by executing a single measurement desired times with the next averaging of the resultant data. The single measurement is implemented by the internal library function declared as "uint16_t adc_ll_read_voltage_once(void);". For the reference see the adc_gpio example available in the library.
  5. The standard default library option provides no averaging inside of the function Adc_ReadGpio(). In this case its internal function adc_ll_read_gpio() calls the function adc_ll_read_voltage_once() just once to implement a single measurement.
  6. If the averaging above is needed, it is responsibility of application to implement it. Melexis is responsible only for the standard default option of the function Adc_ReadGpio().
  7. Any error detected during the function execution can be checked by invoking the function Adc_IsError().

uint16_t Adc_ReadPressure ( void  )

The function measures a signal coming from the pressure sensor.

Returns
an unsigned 16-bit value that represents a raw result of the pressure measurement expressed in LSB of the ADC.
Precondition
Because the function Adc_ReadPressure() reads some calibration data directly from the nvRAM, after each wake up and before calling the function the nvRAM has to be recalled by the library function NvRam_Recall().
Note
  1. The pressure sensor is temporarily enabled during the measurement. After the measurement it is disabled to save energy.
  2. To implement the AD-conversion the function Adc_ReadPressure() calls the internal library function declared as "uint16_t adc_ll_read_pressure(void);".
  3. The library function Calc_Pressure() can be used to convert the returned raw value to the physical unit expressed in [kPa].
  4. The measurement within the input range is implemented with 12-bit resolution and the sensitivity specified in the product datasheet.
  5. The output value 4095 or above represents an ADC overflow.
  6. To implement an efficient averaging inside of the Adc_ReadPressure() function, an application can override the function adc_ll_read_pressure() by executing a single measurement desired times with the next averaging of the resultant data. The single measurement is implemented by the internal library function declared as "uint16_t adc_ll_read_pressure_once(void);". For the reference see the adc_sens example available in the library.
  7. The standard default library option provides no averaging inside of the function Adc_ReadPressure(). In this case its internal function adc_ll_read_pressure() calls the function adc_ll_read_pressure_once() just once to implement a single measurement.
  8. If the averaging above is needed, it is responsibility of application to implement it. Melexis is responsible only for the standard default option of the function Adc_ReadPressure().
  9. Any error detected during the function execution can be checked by invoking the function Adc_IsError().

◆ Adc_ReadPVT()

void Adc_ReadPVT ( Adc_RawPvt_Type *  raw_pvt)

The function measures signals coming from pressure, supply voltage and temperature sensors.

All three output values are raw and expressed in LSB of the ADC.

Parameters
raw_pvtPointer to Adc_RawPvt_Type structure storing measurement result.
Precondition
Because the function Adc_ReadPVT() reads some calibration data directly from the nvRAM, after each wake up and before calling the function the nvRAM has to be recalled by the library function NvRam_Recall().
Note
  1. The function is optimized to minimize power consumption compared to the individual calls to Adc_ReadPressure(), Adc_ReadVoltage() and Adc_ReadTemperature().
  2. Each of 3 sensors is temporarily enabled during the corresponding measurement. After the measurements all sensors are disabled to save energy.
  3. All measurements within the own input ranges are implemented with 12-bit resolution and sensitivities specified in the product datasheet.
  4. For all 3 measurements the output values 4095 or above represent an ADC overflow.
  5. To convert the obtained raw values to the physical units use the respective functions: Calc_Pressure(), Calc_Voltage() and Calc_Temperature().
  6. Because the supply voltage measurement is simplified inside of the function Adc_ReadPVT(), together with better power efficiency it can result a bit worse accuracy in comparison with the normal measurement implemented by the function Adc_ReadVoltage(). A small deviation can be detected for some parts at the corner conditions only.
  7. The function doesn't support an internal averaging.

◆ low_power_adc_read_pressure()

uint16_t low_power_adc_read_pressure ( void  )

The function implements a power optimized pressure measurement with less accurate conversion result.

It can be used to monitor pressure with the next switching to the standard measurement as soon as a pressure change is detected.

Returns
an unsigned 16-bit value that represents a raw result of the pressure measurement expressed in LSB of the ADC.
Warning
Output format of the low_power_adc_read_pressure() is NOT compatible with adc_raw_pressure parameter of the Calc_Pressure() function. Execute the function Adc_ReadPressure() or Adc_ReadPVT() to get a data that can be used for the adc_raw_pressure argument of the function Calc_Pressure()!
Note
  1. The low power pressure measurement is not calibrated in production and hence cannot be converted to the pressure units with the accuracy specified in the datasheet.
  2. The values above 8190 represent ADC overflow.
  3. Any error detected during the function execution can be checked by invoking the function Adc_IsError().
  4. The function doesn't support an internal averaging.
