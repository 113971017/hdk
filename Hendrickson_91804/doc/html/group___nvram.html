◆ NvRam_Recall()

void NvRam_Recall ( void  )

The function recalls the nvRAM by coping a data from its non-volatile storage (EEPROM-layer) to the nvRAM buffer (RAM-layer).

The recall operation is surrounded by the busy-waits to ensure the operation start and returns to the caller always occur when the nvRAM is not busy. The nvRAM recall is required if any access to the nvRAM is needed after a wake-up from SLEEP and DEEP SLEEP mode (warm bootstrap).

◆ NvRam_RestoreHfoTrimming()

void NvRam_RestoreHfoTrimming ( void  )

Restore default HFO trimming from nvRAM.

Precondition
  • Because the function reads the calibration data directly from the nvRAM, after each wake up and before calling the function the nvRAM has to be recalled by the library function NvRam_Recall().
  • Application has to be in the System mode to call this function!
  • After both cold and warm bootstraps the part is configured to be in the System mode by default. If the User mode is set by application after the bootstrap, the function has to be called inside of the SYSTEM_MODE** section managed by the macros ENTER_SECTION and EXIT_SECTION** specified in <atomic.h>.

◆ NvRam_RestoreLfoTrimming()

void NvRam_RestoreLfoTrimming ( void  )

The function reads the default LFO factory calibration data from nvRAM and use it to trim 32 kHz RC generator of LFO.

This RC generator defines 32 kHz accuracy of LFO, time accuracy of the LF transceiver as well as 1 kHz accuracy at SLEEP and DEEP SLEEP when the normal mode of LFO is enabled.

Precondition
  • Because the function reads the calibration data directly from the nvRAM, after each wake up and before calling the function the nvRAM has to be recalled by the library function NvRam_Recall().
  • Application has to be in the System mode to call this function!
  • After both cold and warm bootstraps the part is configured to be in the System mode by default. If the User mode is set by application after the bootstrap, the function has to be called inside of the SYSTEM_MODE** section managed by the macros ENTER_SECTION and EXIT_SECTION** specified in <atomic.h>.

void NvRam_RestoreOscTrimming ( void  )

Read from the nvRAM and apply to both HFO and LFO oscillators all their factory trimming data.

Precondition
  • Because the function reads the calibration data directly from the nvRAM, after each wake up and before calling the function the nvRAM has to be recalled by the library function NvRam_Recall().
  • Application has to be in the System mode to call this function!
  • After both cold and warm bootstraps the part is configured to be in the System mode by default. If the User mode is set by application after the bootstrap, the function has to be called inside of the SYSTEM_MODE** section managed by the macros ENTER_SECTION and EXIT_SECTION** specified in <atomic.h>.
Note
Function restores the following trimming:
  • HFO trimming in the register HFO_FREQ_TRIM
  • LFO trimming in the register LFO_FREQ_TRIM
  • ULPO trimming in the register LFO_FREQ_TRIM_ULP

◆ NvRam_Store()

void NvRam_Store ( void  )

The function stores data from the nvRAM buffer (RAM-layer) into the non-volatile EEPROM-layer of the nvRAM.

The store operation is surrounded by the busy-waits to ensure the store start and returns to the caller always occur when the nvRAM is not busy.

Precondition
nvRAM Store operation is allowed ONLY inside of its operating range from 2.5V till 3.6V.**
