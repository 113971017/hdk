◆ Accel_GToRawX()

int16_t Accel_GToRawX ( int16_t  accel_phys)

The function estimates a number of ADC units [LSB] that corresponds to the measurement of the acceleration change along the X axis.

The estimation uses a sensitivity compensation of the X-axis acceleration sensor.

Parameters
accel_physAcceleration change defined in [g] multiplied by 10.
Returns
Acceleration change defined in ADC units (aka LSB).
Note
  • The function can be used to get a calibrated sensitivity of the X-axis acceleration sensor. For example, with the input value 100, that corresponds to the acceleration 10 g, the function returns the sensitivity value multiplied by 10.
Precondition
Because the function reads some calibration data directly from the nvRAM, after each wake up and before calling the function the nvRAM has to be recalled by the library function NvRam_Recall().
