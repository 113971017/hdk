Detailed Description

Functions to output debug information:

  • via serial interface (SW UART, 115200 baud rate);
  • as logic level pulses on debug pin.

By default, debug functions are disabled and all their invocations are ignored and not included into the final application. To enable debug functions, add -DDEBUG_ENABLED define to CPPLAGS variable in the Makefile.

When enabled, debug functions use GPIO0 for an execution tracing or to deliver a debug data via the SW UART.
