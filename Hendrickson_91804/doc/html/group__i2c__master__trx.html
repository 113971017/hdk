Detailed Description

Group of the I2C functions responsible for the data transmitting and receiving.

The functions provide the SCL rate about 206 kHz (without stretching) at the HFO frequency 8 MHz. Note that this software module is deprecated and hence is not recommended for the new designs. Please, use a code extracted from the i2c_master_fram example instead.

Transmits several consecutive bytes on the I2C bus.

Parameters
I2C_tx_bytes_tablePointer to table of bytes to be sent
I2C_nbytesNumber of bytes to send
Returns
Status:
  • 0 = Transmission was complete without error (meaning that all bytes were acknowledged by slave)
  • 1 or more = Error occurred and indicates how many bytes have not been transmitted
Note
Defining the macro I2C_IGNORE_NACK will avoid that a transmission is aborted when an ACK is missing. To be used depending on the wanted behaviour.
Deprecated:
Since the library version 1.10.5.
