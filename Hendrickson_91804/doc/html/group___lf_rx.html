◆ LfRx_FifoFlush()

void LfRx_FifoFlush ( void  )

Flushes the LFRX FIFO buffer and recover from over- or underrun conditions.

Note
  • LFRX FIFO size is 8 bytes.
  • The flush operation clears the over-/underrun condition (LFRX_FIFO_OVUND = 0) as well as the LFRX FIFO counter (LFRX_FIFO_COUNT = 0).

◆ LfRx_FifoPeekByte()

uint8_t LfRx_FifoPeekByte ( void  )

Reads and returns a byte from the top of the LFRX FIFO buffer.

The buffer is NOT advanced afterwards.

Returns
Data byte read from the top of FIFO buffer.
Note
  • LFRX FIFO size is 8 bytes.
  • When the LFRX FIFO is full (i.e. contains 8 bytes) and a new data byte is being stored to the LFRX FIFO, the LFRX_FIFO_COUNT remains at value 8, and the flags LFRX_FIFO_OVUND and LFRX_FIFO_FULL get set, indicating the overrun condition.
  • To recover from an over- or underrun conditions, the firmware should flush the LFRX FIFO by means of the function LfRx_FifoFlush().

◆ LfRx_FifoReadByte()

uint8_t LfRx_FifoReadByte ( void  )

Reads and returns a byte from the top of the LFRX FIFO buffer.

Afterwards the buffer is advanced (shifted by one to prepare the next byte to read).

Returns
Data byte read from the top of FIFO buffer.
Note
  • LFRX FIFO size is 8 bytes.
  • When the LFRX FIFO is full (i.e. contains 8 bytes) and a new data byte is being stored to the LFRX FIFO, the LFRX_FIFO_COUNT remains at value 8, and the flags LFRX_FIFO_OVUND and LFRX_FIFO_FULL get set, indicating the overrun condition.
  • At the overrun condition the LFRX FIFO cannot be advanced. It means that only the first received byte is readable.
  • To recover from an over- or underrun conditions, the firmware should flush the LFRX FIFO by means of the function LfRx_FifoFlush().

◆ LfRx_ReceivedHeader()

uint32_t LfRx_ReceivedHeader ( void  )

Returns 32-bit word with a received LF header.

Returns
32-bits that includes LFRX_RXD_HDR_H content in its highest word and LFRX_RXD_HDR_L content in its lowest word.
Note
  • For 1 byte LF header (LFRX_HDRLEN = LFRX_HDR_8_BITS = 1) all 4 bytes of the returned 32-bit word include the same value of the received 8-bit LF header.
  • For 2 byte LF header (LFRX_HDRLEN = LFRX_HDR_16_BITS = 2) both 16-bit words of the returned 32-bit word include the same value of the received 16-bit LF header.
  • For 4 byte LF header (LFRX_HDRLEN = LFRX_HDR_32_BITS = 3) the whole returned 32-bit word includes the received 32-bit LF header.
