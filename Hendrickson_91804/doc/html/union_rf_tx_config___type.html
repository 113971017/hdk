uint16_t RfTxConfig_Type::RFTX_DIRECT_MOD

3-bit modulation source selection:

  • 0 = Fixed logic 0
  • 1 = Raw data from FIFO, no preamble, sync pattern or packet
  • 2 = Preamble and sync pattern, no packet

  • 4 = GPIO0 input
