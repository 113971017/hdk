uint16_t LfConfig_Type::LFRX_LONGCNT

Measurement duration for preamble validation: 0 = 5 tRC = 156us nominal (typ.

for unmodulated preamble) 1 = 10 tRC = 313us nominal (typ. for modulated preamble) When LFRX_MINCNT = 0 and LFRX_DELTACNT = 0, preamble validation is skipped entirely
