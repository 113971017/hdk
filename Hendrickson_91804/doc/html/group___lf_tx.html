◆ LfTx_FifoFlush()

static INLINE void LfTx_FifoFlush ( void  )
static

Flush LFTX FIFO buffer.

Note
  • LFTX FIFO size is 8 bytes.
  • The flush operation clears the over-/underrun condition (LFTX_FIFO_OVUND = 0) as well as the LFTX FIFO counter (LFTX_FIFO_COUNT = 0).
