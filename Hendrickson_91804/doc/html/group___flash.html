Detailed Description

Functions to manage the Flash memory content.

Warning
  • Write and Erase operations are strictly forbidden outside of the operating range specified for the Flash programming in the device datasheet: Temperature from 0 till 85 deg C, VDD from 2.5V till 3.3V
  • For safety reasons, it is highly recommended to avoid storing permanently secure keys in memory. Normally, the secure keys shall be received from external device (e.g. via LF communication channel) and shall be cleaned up from the memory after the usage. This prevents a risk of the Flash memory damage due to unexpected code execution after a failure, e.g. caused by a huge electromagnetic disturbance.
  • Please use these functions carefully, because they modify the content of the Flash memory containing application code and Software Libraries, including these functions.

Writes 64 bytes of the data to the specified Flash Page.

Parameters
addressPage address within User Area of the Flash
secure_1Secure key CMD_FLASH_UNLOCK = 0x05648u
secure_2Secure key CMD_FLASH_WRITE = 0x0A5E4u
data64-bytes array of data to be written to the Flash page.
Returns
  • true: operation failed
  • false: operation succeeded
Precondition
  • Write operation is allowed inside of its operating range ONLY: temperature from 0 till 85 deg C, VDD from 2.5V till 3.3V.
  • Melexis does not guarantee the quality of the Flash writing outside of its operating range!
  • Application has to measure both temperature and VDD before Flash writing to ensure it is executed at the correct conditions.
  • The additional current consumption needed for the write operation (up to 10 mA) increases the battery voltage drop. It has to be taken into account to ensure the VDD operating range!
  • Application has to be in the System mode to call this function!
  • After both cold and warm bootstraps the part is configured to be in the System mode by default. If the User mode is set by application after the bootstrap, the function has to be called inside of the SYSTEM_MODE** section managed by the macros ENTER_SECTION and EXIT_SECTION** specified in <atomic.h>.
Note
  • If the LF Bootloader is used, only the pages outside of the Bootloader code can be written to prevent the Bootloader damage.
