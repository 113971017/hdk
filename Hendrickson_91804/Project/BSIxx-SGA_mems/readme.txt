You can use hex_converter.py to convert hex files to C files.
If python is not installed, you can use hex_converter.exe to convert hex files to C files.
Put the hex file in the same folder as the py or exe file.
The hex file name must be MLX91805_tpms_ble.hex.
Open a command prompt window and change the folder to this location, then run hex_converter.py or hex_converter.exe.
If there are no errors, the mlx_memory_image.c file will be generated.
